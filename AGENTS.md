# FLIX remote maintenance

- A request to change the remote means the shared browser/iPhone/Android experience. Use the canonical original page in the parent FLIX workspace and follow `REMOTE_DEVELOPMENT.md`; never require the owner to name both page and app.
- `src/remote-page/source.html` and shared rule files are generated by the build. In this standalone public repository without the private parent, preserve their recorded source receipts. Do not invent private backend configuration.
- Publish the hashed UI manifest and HTML together. Source edits, a local build, package publication and physical device acceptance are separate evidence.
- Preserve direct phone-to-TV LAN transport. Never add a household computer relay.
- Native bridge/plugin changes need a new binary and compatibility review. Shared HTML changes use the verified UI channel in compatible installed shells.
- Respect the owner's background-only TV restriction. Isolated fixtures do not prove actual phone/TV acceptance.
